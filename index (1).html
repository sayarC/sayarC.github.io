01 / Data & Tooling

Retail Price Intelligence Scraper

Python Selenium BeautifulSoup Data Pipeline
Problem
Pulling structured product data from a major retailer's site was unreliable — pages rendered with JavaScript, so a naive request returned nothing useful. The data existed; getting it cleanly and repeatedly was the real problem.
Decisions
Chose Selenium to render JS-heavy pages instead of fighting the markup, paired with BeautifulSoup for parsing. Added CSV checkpointing so a crash mid-run wouldn't lose hours of collected data — a reliability tradeoff that mattered more than raw speed.
Outcome
A resumable pipeline that survives interruptions and produces clean, analysis-ready output. Migrated the workflow from notebooks to a real project structure so it could actually be maintained and re-run.

02 / Systems & Design

Fighting Game Engine (C++)

C++ OOP Systems Design
Problem
Build a fighting game where different characters share core behavior but each play differently — without copy-pasting logic for every character into an unmaintainable mess.
Decisions
Designed a class hierarchy using inheritance and polymorphism so shared mechanics lived in one place while character-specific moves overrode cleanly via virtual functions. The architecture was the product decision — it determined how easily new characters could be added.
Outcome
A working, extensible engine where adding a new fighter meant writing one focused subclass, not rewriting the game. A concrete demonstration of designing for change rather than just for the demo.

03 / Algorithms

Maze Solver & Pathfinding

C++ BFS Data Structures
Problem
Find the shortest path through an arbitrary maze — guaranteed shortest, not just any path that happens to reach the exit.
Decisions
Used breadth-first search because it guarantees the shortest path in an unweighted grid, and implemented the supporting queue from scratch with a linked list to understand the data structure end to end rather than treating it as a black box.
Outcome
A correct, reliable solver — and a working understanding of why a given algorithm fits a given problem, which is the part that transfers to everything else.
